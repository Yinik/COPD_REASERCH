## 一、项目概述

### 1.1 研究背景

慢性阻塞性肺疾病（Chronic Obstructive Pulmonary Disease, COPD）是全球第三大死亡原因，中国患病人数近1亿。COPD临床知识分散在大量医学文献、指南和专家共识中，医生获取系统性知识成本高、效率低。如何**从海量医学文本中自动抽取结构化知识**并构建可查询的知识图谱，是智慧医疗领域的关键问题。

### 1.2 研究目标

本项目旨在构建COPD领域的专业知识图谱，实现：
- **输入**：一段COPD临床文本或医学文献
- **处理**：自动识别医学实体（疾病、症状、药物等），抽取实体间关系
- **输出**：结构化三元组 + Neo4j可视化知识图谱

### 1.3 核心指标

| 指标 | 目标值 | 当前达成 |
|------|--------|---------|
| 核心文献处理量 | 50篇 | ✅ 50篇 |
| 实体数量 | 150~250个 | ✅ 126个（7类） |
| 关系三元组 | 200~350条 | ✅ 675条（13类） |
| 图谱连通率 | 100%连通 | ✅ 100% |
| 人工审核准确率 | ≥95% | ✅ 已逐条审核 |

## 五、核心功能模块

### 5.1 文献清洗与预处理

**技术方案**：
- 采用 `pdfplumber` 进行PDF文本提取
- 定制化规则去除页眉页脚（基于正则匹配重复行）
- 断行合并：检测句末无标点的行进行跨行合并
- 参考文献截断：识别"参考文献"章节并去除

**产出成果**：
- 50篇核心文献清洗完成
- 清洗后文本总量：约49万中文字符
- 建立标准化文本处理流程

### 5.2 种子词典构建

**三步构建法**：
1. **术语切分**：结合规则匹配与统计方法生成候选术语
2. **质量打分**：基于词频、文档分布、PMI、信息熵等统计特征评估术语质量
3. **人工分类**：由项目小组成员逐条审核并分类为7种实体类型

**词典统计**：

| 实体类型 | 英文标签 | 数量 | 示例 |
|----------|---------|------|------|
| 疾病 | Disease | 27 | 慢性阻塞性肺疾病、支气管哮喘、肺动脉高压 |
| 症状 | Symptom | 24 | 呼吸困难、慢性咳嗽、咳痰、胸闷 |
| 药物 | Medication | 35 | 吸入性糖皮质激素、支气管舒张剂、茶碱类药物 |
| 治疗方式 | Treatment | 14 | 肺康复、戒烟、无创通气、肺减容手术 |
| 检查 | Examination | 9 | 肺功能、CT、血气分析、心电图 |
| 危险因素 | RiskFactor | 12 | 吸烟史、空气污染、呼吸道感染 |
| 并发症 | Complication | 5 | 肺动脉高压、右心衰竭、抑郁症 |
| **合计** | | **126** | |

### 5.3 关系抽取

**技术架构**：
- **基于规则模板**：构建13类医学关系的正则模板
- **BERT增强实验**（探索性）：采用 `bert-base-chinese` 进行初步微调探索，因标注数据规模有限，目前以规则方法为主

**13类关系类型**：

| 关系类型 | 数量 | 示例 |
|----------|------|------|
| 药物-治疗-疾病 | 129 | 吸入性糖皮质激素 → 治疗 → COPD |
| 疾病-症状 | 100 | COPD → 症状 → 呼吸困难 |
| 诱发-急性加重 | 87 | 呼吸道感染 → 诱发 → COPD急性加重 |
| 药物-缓解-症状 | 87 | 支气管舒张剂 → 缓解 → 呼吸困难 |
| 检查-辅助诊断-疾病 | 56 | 肺功能 → 辅助诊断 → COPD |
| 治疗-改善-症状 | 54 | 肺康复 → 改善 → 运动耐力 |
| 疾病-并发症 | 50 | COPD → 并发症 → 肺动脉高压 |
| 危险因素-疾病 | 38 | 吸烟史 → 危险因素 → COPD |
| 疾病-治疗 | 34 | COPD → 治疗 → 肺康复 |
| 检查-评估-症状 | 24 | 血气分析 → 评估 → 低氧血症 |
| 检查-评估-疾病 | 12 | CT → 评估 → 肺气肿 |
| 药物-导致-并发症 | 3 | 糖皮质激素 → 导致 → 骨质疏松症 |
| 检查-筛查-疾病 | 1 | 肺功能 → 筛查 → COPD |
| **合计** | **675** | |

**质量控制**：
- 原始抽取：1,247条
- 人工审核：两名成员独立审核 → 争议讨论 → 最终确认
- 方向规范化：统一疾病为头实体，消除"相关"等模糊关系
- 最终保留：675条（准确率经人工确认达95%以上）

### 5.4 知识图谱构建（Neo4j）

**数据规模**：
- 节点：126个实体（7种类型）
- 关系：675条（13种类型）
- 结构：以"慢性阻塞性肺疾病"为中心的辐射型有向图
- 连通性：100%实体可从COPD出发到达

**导入方式**：
- 提供 `nodes.csv` + `relations.csv` + `import.cypher`
- 支持 Neo4j Browser 逐段执行
- 提供详细导入教程（`Neo4j导入教程.md`）

### 5.5 端到端演示系统

**功能**：输入一段COPD临床文本 → 自动识别实体 → 抽取关系 → 实时更新Neo4j图谱

**运行方式**：
```bash
python COPD图谱端到端抽取系统.py
```

- Python 3.10+
- Neo4j Desktop（用于知识图谱可视化，可选）

### 6.2 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/Yinik/COPD_REASERCH.git
cd COPD_REASERCH

# 2. 创建虚拟环境（推荐）
python -m venv .venv
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac

# 3. 安装核心依赖
pip install pdfplumber pandas python-docx neo4j requests

# 或安装全部依赖
pip install -r requirements.txt

# 4. 复制配置文件模板
# 将 config_template.py 复制为 config.py，并根据本地路径修改

# 5. 运行端到端演示
python COPD图谱端到端抽取系统.py
```

详见 `关系抽取结果/Neo4j导入教程.md`，核心步骤：

```bash
# 3. 在Neo4j Browser中执行 import.cypher 中的语句
```
